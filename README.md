# Team-Battle 🃏⚔️

Team-Battle is a **turn-based, card-randomizer role game** built with **Next.js**.  
Players draw random character cards from popular anime universes and manually assign them to predefined roles.

This project is built for **personal gameplay with friends** and focuses on clean game logic, randomness, and an interactive UI.

---

## 🎮 Game Concept

- Players take turns drawing **face-down character cards**
- Each character can be used **only once per game**
- Players manually assign characters to limited roles
- Each player has **one optional skip per game**
- Roles include:
  - Captain
  - Vice-Captain
  - Tank
  - Healer
  - Assassin
  - Support (x2)
  - Traitor

---

## 🧩 Anime Character Sets

Currently supported anime:
- **Naruto**
- **Bleach**
- **Jujutsu Kaisen**
- **Demon Slayer**

Each anime has its own character dataset stored locally and used during gameplay.
